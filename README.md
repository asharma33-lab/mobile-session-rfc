# mobile-session-rfc

Public SDK feedback and implementation artifacts for the **mobile session recovery specification**.

The default branch includes the current recovery coordinator and privacy-safe
error contract under `src/session/`. Open pull requests retain earlier decision
analysis, compatibility evidence, and public contract history.

Tracked in Jira:

- Epic: [MOBL-59](https://one-atlas-qdiv.atlassian.net/browse/MOBL-59)
- Customer-feedback coordination: [MOBL-63](https://one-atlas-qdiv.atlassian.net/browse/MOBL-63)
- Session policy decision: [MOBL-60](https://one-atlas-qdiv.atlassian.net/browse/MOBL-60)
